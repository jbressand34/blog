# Créer le diagramme C4 — Couche Contexte

Tu dois **générer ou mettre à jour** le fichier `.spec/03_C4_CONTEXT_LAYER.puml` pour qu’il contienne un **diagramme PlantUML** représentant la **couche Contexte (niveau 1)** du modèle C4 pour l’application.

## Instructions

1. **Lis** les fichiers `.spec/01_USER_STORIES.md` et `.spec/02_ARCHITECTURE_CHOICES.md` pour identifier :
   - Le **système** principal (l’application, ex. le blog).
   - Les **personnes** (acteurs) qui interagissent avec le système (ex. blogueur, visiteur).
   - Les **systèmes externes** avec lesquels le système interagit (ex. dépôt Git, plateforme d’hébergement type Vercel).

2. **Génère** un diagramme PlantUML au format **C4 Context** :
   - Utilise la librairie **C4-PlantUML** en incluant `C4_Context.puml` (URL standard : `https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Context.puml`).
   - Déclare **Person**(alias, "Nom affiché", "Description") pour chaque acteur.
   - Déclare **System**(alias, "Nom du système", "Description") pour l’application (système en scope).
   - Déclare **System_Ext**(alias, "Nom", "Description") pour chaque système externe.
   - Déclare les **relations** avec **Rel**(source, cible, "Description") ou **Rel**(source, cible, "Description", "Technologie") pour les interactions (qui fait quoi avec qui).

3. **Écris** le résultat dans `.spec/03_C4_CONTEXT_LAYER.puml` :
   - Si le fichier existe déjà : remplace son contenu par le diagramme généré (en te basant sur la spec actuelle).
   - Si le fichier ou le dossier `.spec/` n’existe pas : crée-les puis écris le fichier.

4. **Structure type** du fichier :
   - Un bloc `@startuml` / `@enduml` avec un titre adapté (ex. `C4_Context - Blog`).
   - L’`!include` vers `C4_Context.puml`.
   - Les éléments Person, System, System_Ext et les Rel cohérents avec les user stories et les choix d’architecture.

5. **Réponds** à l’utilisateur en résumant : ce qui a été mis dans le diagramme (système, acteurs, systèmes externes, relations) et le chemin du fichier créé ou mis à jour.

## Rappel C4 — Niveau Contexte

La couche Contexte répond à : *« Quel est le système et qui l’utilise ou interagit avec lui ? »*. On ne détaille pas l’intérieur du système, seulement ses frontières et les flux avec les personnes et les systèmes externes.
